# Håp Norge - NGO Website Template

Modern, responsive single-page website template for humanitarian organizations with 3D effects and animations.

## 🚀 Features

- **Single-page design** - Smooth scrolling navigation
- **3D slider** - Premium hero slider with 4 slides
- **Fully responsive** - Works on all devices
- **3D effects** - Particle system, animations, glassmorphism
- **Sections included** - About, Programs, Team, Donate, Contact

## 📦 Quick Start

1. Clone or download the repository
2. Open `index.html` in your browser
3. That's it!

## 🎨 Customization

Replace "Håp Norge" with your organization name in `index.html`

Update colors in `color-fixes.css`:
- Primary: `#1e3a8a` (Navy blue)
- Accent: `#667eea` (Purple)

## 📁 Files

```
index.html              # Main website
styles.css              # Base styles
slider-3d-enhanced.css  # 3D slider
site-3d-effects.css     # 3D effects
color-fixes.css         # Colors
script.js               # Main JS
slider-3d.js            # Slider
site-3d-effects.js      # Effects
particles.js            # Particles
```
