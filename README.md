# Håp Norge - Premium NGO Website Template

En moderne, responsiv single-page nettside for Håp Norge, en humanitær organisasjon fokusert på utdanning, helsehjelp og samfunnsutvikling. Dette er en fullstendig NGO-mal med 3D-effekter, animasjoner og moderne design.

## 🌟 Features

### Design & Brukeropplevelse
- **Moderne, rent design** - Profesjonelt og troverdig utseende
- **Fullt responsiv** - Fungerer perfekt på desktop, nettbrett og mobile enheter

## 🚀 Komme i gang

### Forhåndskrav
- En moderne nettleser (Chrome, Firefox, Safari, Edge)
- Ingen ekstra programvareinstallasjon nødvendig

### Installasjon
1. Klon eller last ned prosjektfilene
2. Åpne `index.html` i nettleseren din
3. Nettsiden er klar til bruk!

### Filstruktur
```
ngo/
├── index.html          # Homepage
├── about.html          # About Us page
├── programs.html       # Programs page
├── donate.html         # Donation page
├── styles.css          # Main stylesheet
├── script.js           # Main JavaScript functionality
├── donate.js           # Donation form JavaScript
└── README.md           # Project documentation
```

## 🎨 Tilpasning

### Merkevare
- **Organisasjonsnavn**: Oppdater "Håp Norge" gjennom filene
- **Farger**: Endre fargepaletten i `styles.css` (primær: #e74c3c, sekundær: #667eea)
- **Logo**: Erstatt hjerteikonet med organisasjonens logo
- **Kontaktinformasjon**: Oppdater kontaktdetaljer i alle HTML-filer

### Innhold
- **Oppdrag & Verdier**: Rediger oppdragserklæring og verdier i `about.html`
- **Programmer**: Endre programdetaljer i `programs.html`
- **Teammedlemmer**: Oppdater teaminformasjon i `about.html`
- **Statistikk**: Endre innvirkningstall gjennom siden

### Styling
- **Fonter**: Siden bruker Inter-fontfamilien - endre i CSS
- **Layout**: Endre rutenettlayout og avstand i `styles.css`
- **Animasjoner**: Juster overgangseffekter og animasjoner

## 🎨 Customization Guide

### Change Organization Name
Search and replace "Håp Norge" with your organization name throughout:
- `index.html`
- `README.md`

### Update Colors
Edit `color-fixes.css` to change the color scheme:
```css
/* Primary colors */
--primary-blue: #1e3a8a;
--primary-purple: #667eea;
--accent-purple: #764ba2;
```

### Modify Content
1. **Hero Slider**: Edit slides in `index.html` (lines 50-247)
2. **About Section**: Update organization history (lines 278-319)
3. **Programs**: Modify program cards (lines 322-442)
4. **Team**: Update team members (lines 469-510)
5. **Contact**: Change contact information (lines 494-537)
